# Последний огонь Дзержинска

Изометрическая зомби-игра для Telegram Mini App в стиле кукольной покадровой анимации. Действие происходит в центре Дзержинска.

Лёва Сомов возвращается в родной город за сестрой Асей. Город захвачен мёртвыми, а военные обещают сжечь центр через две ночи.

**Играть:** откройте `index.html` через GitHub Pages (Settings → Pages → Deploy from branch `main`, папка `/`).

## Состав
- `index.html` — собранная игра (весь код внутри)
- `t/` — тайлы города, `sp/` — атласы персонажей
- `mm/` — тайлы карты-схемы
- `snd/` — музыка и звуки
- `slides/` — картинки вступления и кат-сцен
- `src/` — исходники; `python3 build.py` в папке `src` пересобирает `index.html`. Для этого нужен `world.json` уровнем выше, его нет в репозитории.

## Управление
Телефон: джойстик и кнопки. ПК: WASD, клик / J — огонь, E — действие, R — перезарядка, Q — оружие, H — аптечка, M — карта.
